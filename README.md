# UBM Documentation Repository

This repository contains the technical documentation, setup instructions, and
development guides for the UBM Driverless projects.

## Documentation Website

Start from the documentation landing page:

**[Open the UBM Driverless Documentation](https://ubm-driverless.github.io/ubm-docs/)**

From there, you can access the FSAE and F1Tenth guides, simulator documentation,
setup instructions, and generated package references.

## Contributing Documentation

Documentation source files are stored in [`docs/`](docs/), and the website is
built with MkDocs when changes reach `main`.

Before adding or editing pages, read the
[Add Documentation Guide](https://ubm-driverless.github.io/ubm-docs/guides%20F1tenth/ADD_DOCUMENTATION/).

For details about the build and deployment pipeline, see
[`docs/setup/DOCS_GENERATION.md`](docs/setup/DOCS_GENERATION.md).
