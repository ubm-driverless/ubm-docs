# Start Here

Use this section to choose the correct platform and documentation path before
setting up software or operating a vehicle.

## Choose the platform

- **Formula Student Driverless:** use the ROS 2 pipeline in `ubm-fsae`. Start
  from the [Formula Student section](../platforms/fsae/index.md).
- **RoboRacer:** use AuRoRus, the current Rust stack. Start from the
  [RoboRacer section](../platforms/roboracer/index.md).
- **Previous F1Tenth ROS stack:** use only for maintenance or historical
  reproduction. It is under
  [Legacy ROS F1Tenth documentation](../platforms/roboracer/legacy-ros/index.md).
- **Simulation and integration:** use the
  [Simulator guides](<../guides Simulator/index.md>).

## Shared information

- [Concepts and standards](../concepts-and-standards/index.md) contains shared
  data formats and conventions.
- [Tools](../tools/index.md) contains operator and analysis tools.
- [Development](../development/index.md) contains contribution and software
  engineering workflows.
