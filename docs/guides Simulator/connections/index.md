# Simulator Connection and Integration Guides

This section contains focused procedures for connecting the Unity and NavSim
simulators to ROS 2, rosbridge, ROS-TCP-Endpoint, Foxglove, and multi-computer
test environments.

- [Unity, NavSim, ROS 2 and Foxglove](UNITY_NAVSIM_ROS_TRANSPORTS.md) explains
  the available transports and the recommended combined architecture.
- [Integrated Unity and p5.js TrackSim test](UNITY_P5JS_ODOMETRY_TEST.md)
  describes a local odometry integration test.
- [NavSim on Ubuntu and Unity on Windows](UNITY_P5JS_ODOMETRY_WINDOWS_UBUNTU_TEST.md)
  adapts the odometry test to two computers.
- [Unity Windows, ROS 2 Ubuntu and visualization](UNITY_ROS_TCP_VISUALIZATION_GUIDE.md)
  covers ROS-TCP, Camera WebGUI, and Foxglove visualization.

For simulator installation, features, menus, and normal operation, return to
the main [Simulator Guides](../index.md).
