# Simulator Guides

This section collects the guides used to create and run simulated driving
scenarios and to connect NavSim, Unity, ROS 2, and Foxglove across the Ubuntu
and Windows development machines.

Start with the
[NavSim TrackGen Simulator guide](NAVSIM_TRACKGEN_SIMULATOR.md) to create 2D
tracks, simulate vehicle navigation, and publish odometry and landmarks for the
`ubm-fsae` pipeline.

Use the [Unity Simulator guide](UNITY_SIMULATOR.md) for the 3D Formula Student
simulator, including installation, tracks, vehicles, ROS transports, simulated
LiDAR and stereo-camera data, runtime menus, controls, and troubleshooting.

The [Connection and Integration guides](connections/index.md) provide focused
ROS-TCP and ROS# / rosbridge configurations, Foxglove visualization
procedures, and small end-to-end odometry test setups.
