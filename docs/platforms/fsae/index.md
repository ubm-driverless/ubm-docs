# Formula Student Driverless

This section contains procedures, references, and best practices for the
Formula Student Driverless vehicle and software stack.

The Formula Student vehicle continues to use the ROS 2 pipeline in
`ubm-fsae`. This is separate from RoboRacer, whose current stack is AuRoRus in
Rust.
