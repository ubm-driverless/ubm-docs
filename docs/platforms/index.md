# Platforms

UBM Driverless currently maintains two distinct autonomous-driving stacks.

## Formula Student Driverless

The full-size Formula Student vehicle uses ROS 2 and the `ubm-fsae` pipeline.
Open the [Formula Student section](fsae/index.md).

## RoboRacer

The small-scale racing platform, formerly called F1Tenth, now uses the AuRoRus
stack written in Rust. Open the [RoboRacer section](roboracer/index.md).

The old ROS F1Tenth stack is retained only as
[legacy documentation](roboracer/legacy-ros/index.md).
